# sistema-cadastro-python
Trabalho desenvolvido durante o curso técnico de Informática. O programa roda pelo terminal e permite gerenciar cadastros de pessoas com nome, idade e e-mail.

Funcionalidades: cadastrar pessoas,listar os cadastros,buscar por nome,remover por nome e salvar os dados em arquivo.txt .

Pra usar, precisa do Python instalado e rodar no terminal.
Um menu irá aparecer com as opções numeradas.
